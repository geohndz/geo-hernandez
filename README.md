# Geo Hernandez — Portfolio

Product design portfolio for Geo Hernandez — product and interaction design for information-heavy tools, prototyped in code. Custom-coded rebuild of [geovanyhernandez.com](https://geovanyhernandez.com/) in Next.js, Tailwind CSS, and Motion.

Live: [geohernandez.xyz](https://geohernandez.xyz)

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Motion
- MDX case studies

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
